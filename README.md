# rm-git-lab-template
Starter project for the Git Learning Portal. Click Use this template, include all branches, and name your copy git-lab.

## Your card

`index.html` is a small portfolio card. Open it in a browser, or turn on GitHub Pages (Settings → Pages → Deploy from a branch → main) and visit `https://YOUR-USERNAME.github.io/git-lab/`.

Change `YOUR NAME` and `YOUR-USERNAME` in `index.html`, commit, and push. The card updates with your name.
